# ReconLogic Setup (Python 3.14 + FastAPI, npm for client)
1. Server: pip install -e . (FastAPI, SQLAlchemy, Pandas, pydantic)
2. Client: npm install (Next.js, Tailwind)
3. Docker: docker-compose up (Postgres + Redis)
4. Alembic: alembic upgrade head
Rules: Decimal never float, LLM never arithmetic, Structured Outputs, human sign-off, 300 transactions
